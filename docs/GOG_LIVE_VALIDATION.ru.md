# Проверка действующей раздачи GOG — 31 октября 2026

Подтверждена работа существующего модуля GOG на **A New Beginning: Final Cut**, `gog:1207659150`. Изменять алгоритм обнаружения для этой раздачи не потребовалось. Версия расширения остаётся 2.1.1; новый релиз не создавался.

## Источник и условия

- Публичная главная: https://www.gog.com/en/ — блок раздачи и кнопка Add to library.
- Страница игры: https://www.gog.com/en/game/a_new_beginning.
- Конфигурация: `https://sections.gog.com/v1/pages/2f?countryCode=US&locale=en-US&currencyCode=USD`.
- Секция: `https://sections.gog.com/v1/pages/2f/sections/5fc1d634-cb15-4288-a390-3d4da7d981b6?countryCode=US&locale=en-US&currencyCode=USD`.
- Секция публичная: `visibilityControl: ALL`, `isPersonalized: false`, `hideOnLoad: false`.
- Срок: **2 ноября 2026, 17:00:59 МСК** (`2026-11-02T14:00:59Z`). Начало в ответе отсутствует и не выдумывается.
- Платформы: Windows и Mac (`osx` преобразуется в `mac`). Жанры в этой секции отсутствуют; теги не подменяют жанры.
- Обычная цена покупки во время проверки: US $0.99 при базовой $9.99; RU $0.29 при базовой $3.09. Это не цена получения через отдельную раздачу на главной. Каталог товаров со скидкой до нуля пуст; именно секция подтверждает бесплатное получение.
- На сайте получение связано с согласием на маркетинговые сообщения GOG. Аккаунт, принятие условий и получение игры выполняет сам пользователь; при проверке кнопка получения не нажималась.

## Проверенный результат

Проверка выполнена через рабочий service worker MV3 в отдельном чистом Chromium-профиле с отключёнными системными уведомлениями. Для US и RU GOG вернул одно действующее предложение, без предупреждений; общая проверка всех трёх магазинов завершилась успешно. Подтверждены название, идентификатор, конец акции, исходная цена, платформы, загруженная обложка, присутствие в popup и истории. Кнопка магазина использует адрес получения на главной; название ведёт на страницу игры.

Сетевые запросы обнаружения выполняются без авторизации. Отдельный запуск Node в этой среде дал `fetch failed`; те же публичные API успешно ответили через PowerShell и рабочее расширение в Chromium. Настройки сети и защиты не менялись.

Сокращённый реальный ответ: `tests/fixtures/gog-a-new-beginning.json`. Тесты `tests/gog-live-fixture.test.js` проверяют извлечение данных при ненулевой обычной цене, точную границу завершения, отказ при отсутствии срока, сохранение предложения в истории, одну отправку уведомления без дублей и отсутствие запросов получения игры. Проверка уведомлений здесь программная; реальный баннер ОС не тестировался.

Локальные полные ответы и доказательства: `dist/gog-live-2026-10-31/`; отчёт рабочего расширения и снимки обеих тем: `dist/gog-live-2026-10-31/browser/`. Регион — параметр запроса, а не подтверждение получения игры с IP каждой страны.

Пометка `sectionSchemaLiveVerified: true` означает, что разработчик проверил схему на реальной раздаче. Это не гарантия наличия раздачи в каждом сканировании или обнаружения всех акций GOG.
