# Проверка источников для расширения нескольких магазинов

Актуализация: по решению пользователя проект переименован в **Free Games Watcher**, версия **2.0.0**, репозиторий `Grim1313/Free-Games-Watcher`. Ниже сохранён исторический отчёт этапа; старые названия, запрет публикации и статус предварительной сборки относятся к тому этапу. Текущие инструкции: [TECHNICAL.md](../TECHNICAL.md).

Дата: **26 октября 2026 года**. Прямые проверки выполнены примерно в **15:09–15:20 МСК**. Это снимок доступности и данных, а не гарантия их неизменности.

После этого исследования началась реализация: [план](MULTISTORE_PLAN.ru.md), [результат и проверки](MULTISTORE_IMPLEMENTATION.ru.md). Описанные ниже неизменённые файлы относятся к состоянию на момент аудита.

## Решение и границы этапа

Развивать существующий проект. Первый набор: **Steam, Epic Games Store, GOG**. Переименование, миграция хранилища и подключение новых магазинов к рабочему расширению ещё не выполнялись. Название Game Promo Watch остаётся предложением, не утверждённым названием.

Цель проверки — обнаружение временных раздач игр навсегда без входа, cookies, ключей API и серверной части. Получение игры выполняет пользователь в магазине. Постоянно бесплатные игры, демо, бесплатные выходные и платные подписки не становятся раздачами только из-за цены 0.

Добавлены исследовательские инструменты в `scripts/`, не импортируемые рабочим расширением. Его `src/`, manifest, интерфейс и настройки не изменены. Новые зависимости не установлены.

## Сеть и полный доступ

До переключения чата действовало ограничение сети; запросы возвращали общее `fetch failed`, без сохранённого кода причины. После включения пользователем «Полного доступа» те же адреса EGS и GOG вернули HTTP 200. Steam также доступен.

Дополнительно проверено:

- Node.js 24.14.1: запросы проходят и с `--use-system-ca`, и **без этого параметра**, с обычной проверкой TLS.
- Отдельное тестовое расширение Manifest V3 в изолированном Chromium 151: 9 публичных запросов возвращают HTTP 200 с валидной структурой; один контрольный запрос возвращает ожидаемый 401.
- Все запросы выполняются с `credentials: "omit"`. Cookies в чистом профиле: **0 до / 0 после**; в 14 наблюдаемых браузерных запросах нет Cookie и Authorization. Извлечённые результаты Node и фонового процесса расширения совпали для всех 10 проверок.
- Прокси, DNS, сертификаты, антивирус и личная конфигурация Codex не менялись. Отключение проверки сертификатов не требуется.

Практически проблема доступа к публичным источникам устранена переключением режима. Точную первопричину старого отказа на уровне ОС нельзя восстановить по одному прежнему `fetch failed`; ограничение сети — наиболее вероятное объяснение, согласующееся с изменением режима и повторной проверкой.

Два отдельных ответа серверов **не являются этой сетевой проблемой**:

1. `https://www.gog.com/giveaway/status` → **401 Unauthorized**. В текущем публичном коде GOG этот запрос вызывается после проверки входа и возвращает состояние получения раздачи пользователем. Для анонимного обнаружения его использовать не нужно. Запросы получения игры не выполнялись.
2. Страницы товаров EGS при прямом запросе из Node → **403**, `server: cloudflare`, `cf-mitigated: challenge`. Проверены страницы двух текущих игр. Защита не обходилась. При этом JSON раздач доступен из Node и расширения, а обе обложки возвращают 200/image/png. Фоновое сканирование не следует строить на HTML карточек EGS. Интерактивное открытие этих ссылок пользователем в обычном браузере отдельно не проверялось.

При повторном отказе запускать аудит: он сохраняет HTTP-статус либо `error.message`, `error.cause` и код причины. `401`, `403`, ошибка сертификата и отсутствие сетевого доступа должны диагностироваться раздельно. Сейчас дополнительных действий от пользователя не требуется.

## Результаты по магазинам

| Источник | Проверка без входа | Результат |
|---|---|---|
| Steam: search, featured, appdetails, reviews, StoreBrowse через существующие модули | US и RU | Валидные ответы; найдена 1 акция DLC в обоих регионах; срок и метаданные извлечены |
| EGS: `freeGamesPromotions` | US и RU, Node и MV3 | В US 13 записей: 2 текущие раздачи и 1 будущая; в RU 9 записей: 2 текущие, будущих подтверждённых нет |
| GOG: публичная главная и встроенный JSON | Node | HTML около 1,58 МБ содержит `gogcom-store-state`; служит источником сведений о запросах магазина |
| GOG: конфигурация главной `sections.gog.com` | US и RU, Node и MV3 | 21 секция; `GIVEAWAY_SECTION` в текущей конфигурации отсутствует; ответ около 4,9 КБ |
| GOG: бесплатные товары со скидкой `catalog.gog.com` | US и RU, Node и MV3 | Корректный пустой результат, `productCount: 0`; ответ около 14 КБ |
| GOG: контрольная выборка бесплатного каталога | US, Node и MV3 | Получены 5 карточек с ID, ценами, изображениями, ОС, жанрами и отзывами; встречаются демо с базовой ценой 0 |

Параметр региона проверяет ответ для выбранного рынка с текущего подключения. Это **не проверка из географического IP каждой страны**, не подтверждение возможности покупки/получения и не обход региональных ограничений.

### Steam

Использованы существующие `scripts/check-live.mjs US` и `RU`: по 7 страниц поиска на регион, `complete: true`, **`coverageLimited: true`** из-за лимита страниц. Featured не добавил акций. Транспортный успех не означает полный охват Steam.

Извлечённый пример:

- `app:5340370` — **Popcorn & Premieren - Ausgehviertel**.
- Тип: DLC; ОС: Windows, macOS; жанры: Simulation, Strategy; отзывов: 0.
- Конец: `2026-10-29T17:00:00.000Z` (**29 октября, 20:00 МСК**).
- Стандартный фильтр DLC скрывает эту акцию; это ожидаемое поведение.

### Epic Games Store

Проверенный адрес:

```text
https://store-site-backend-static.ak.epicgames.com/freeGamesPromotions?locale=en-US&country=US&allowCountries=US
```

Для RU меняются **оба** параметра страны. `locale` задаёт язык, а не регион.

| Акция | US | RU | Начало и конец в МСК |
|---|---|---|---|
| Sker Ritual | Текущая; базовая цена $24.99 | Текущая; базовая цена 749 RUB | 22 октября 18:00 — 29 октября 18:00 |
| Home - A Unique Horror Adventure | Текущая; базовая цена $4.99 | Текущая; базовая цена 150 RUB | 22 октября 18:00 — 29 октября 18:00 |
| Sorry We're Closed | Будущая; сейчас цена $17.49 | В ответе нет | 29 октября 18:00 — 5 ноября 19:00 |

Для каждой подтверждённой записи извлечены namespace + offer ID, название, тип предложения, ссылка из `catalogNs.mappings`, обложка, базовая/текущая цена, валюта, число десятичных знаков и даты UTC. Жанры, ОС и сопоставимый рейтинг оставлены неизвестными: ответ содержит числовые теги, но их значения не следует угадывать.

Критерии текущей раздачи в прототипе:

1. Есть активное окно `promotionalOffers`, `startDate <= now < endDate`.
2. В этом окне `discountType: PERCENTAGE`, **`discountPercentage: 0`**.
3. Текущая цена численно равна 0, исходная цена больше 0.

Наблюдаемая семантика `discountPercentage` — остающаяся доля цены: например, 20 соответствует цене $3.99 вместо $19.99. Проверка на значение 100 здесь была бы ошибкой. Категория `freegames` сама по себе также не доказывает раздачу: в ответе есть обычные платные скидки и бывшие участники акций.

Будущие раздачи извлекаются отдельно из `upcomingPromotionalOffers`, только при нулевой доле цены и будущей дате старта. Их текущая цена может быть ненулевой. Результаты с отсутствующим сроком или неверной структурой не подменяются успешным пустым списком.

### GOG

Адреса найдены в данных и публичном JavaScript самой страницы GOG и проверены прямыми запросами:

```text
https://sections.gog.com/v1/pages/2f?countryCode=US&locale=en-US&currencyCode=USD
https://catalog.gog.com/v1/catalog?limit=48&page=1&order=desc:trending&price=between:0,0&discounted=eq:true&countryCode=US&locale=en-US&currencyCode=USD
```

`2f` — наблюдаемый ключ конфигурации главной страницы `/`. Для метаданных можно запрашивать небольшую выборку каталога; разбирать 1,58 МБ HTML при каждой проверке не требуется.

Доступные поля: `id`, `title`, `storeLink`, `coverHorizontal`, `productType`, `price.baseMoney`, `price.finalMoney`, `operatingSystems`, `genres`, `tags`, `reviewsRating`, `reviewsCount`. В каталоге не подтверждены поля начала/конца именно раздачи. Рейтинг сохраняется как исходное значение, без превращения в процент положительных отзывов Steam.

Контрольный пример — Office Party Tech Demo: тип `game`, но тег `demo`, базовая и текущая цены 0. Поэтому фильтра `productType=game` недостаточно. Его карточка и обложка доступны по HTTP 200, но эта запись **не считается временной раздачей**.

**Дополнение от 31 октября 2026:** положительный ответ активной секции получен и проверен на A New Beginning: Final Cut; подтверждены идентификатор, ссылка, обложка, платформы и срок. См. [отчёт проверки](GOG_LIVE_VALIDATION.ru.md).

Живая проверка `GIVEAWAY_SECTION` завершена 31 октября 2026 года; реальный пример добавлен в тесты, включая переход в завершённое состояние по сроку. Для получения игры пользователь самостоятельно принимает условия GOG.

## Общая модель будущей реализации

- Идентичность предложения: магазин + ID товара/предложения; идентичность кампании отдельно. «Забрал» в Steam не означает «забрал» в EGS.
- Общие поля: магазин, регион, ID, название, URL, обложка, тип контента, исходная/текущая цена и единицы её хранения, валюта, начало/конец, текущая/будущая акция, источник подтверждения.
- Неизвестные сроки, рейтинг и платформы остаются неизвестными. Steam хранит цены в минимальных единицах в некоторых API; EGS предоставляет decimals; GOG отдаёт десятичные строки денежных сумм. Прототип сохраняет исходную семантику, производственный формат ещё предстоит унифицировать.
- Ошибки, последнее успешное обновление, полнота охвата, регион и кэш — отдельно по магазинам.
- Сайт магазина может изменить внутренний endpoint. Это наблюдаемые публичные интерфейсы, не гарантированный сторонним разработчикам стабильный API.
- Запросы выполняются из фонового процесса расширения с разрешением на конкретные домены. Проверка Node сама по себе не доказывает работоспособность в браузере, поэтому проведена отдельная проверка MV3. Окончательные разрешения рабочего расширения ещё не изменены.

## Повторение проверки

Без установки зависимостей:

```powershell
npm run audit:sources
# Или один рынок:
npm run audit:sources -- US
# Полная текущая цепочка Steam:
node scripts/check-live.mjs US
node scripts/check-live.mjs RU
```

Аудит выполняет 10 запросов для US + RU, максимум по 3 одновременно, таймаут 25 секунд на запрос. Не перебирает весь каталог и не работает по расписанию. Результаты и сырые тела ответов сохраняются в `dist/source-audit/<UTC-время>/`; краткий указатель с отчётом — `dist/source-audit/latest-node.json`. HTTP 401 у контрольного account-status ожидаем и не маскируется под сетевую ошибку.

Проверка реального фонового процесса MV3 использует существующее внешнее тестовое окружение Playwright, как и остальные браузерные проверки проекта:

```powershell
# Указать существующий Playwright при отсутствии локального пакета:
$env:PLAYWRIGHT_MODULE = 'C:\path\to\playwright\index.mjs'
# Необязательно: путь к имеющемуся тестовому Chromium с поддержкой загрузки расширений:
$env:SOURCE_AUDIT_CHROMIUM = 'C:\path\to\chromium\chrome.exe'
npm run audit:sources:browser
```

Браузерная проверка создаёт отдельные временные расширение и профиль внутри `dist/source-audit/`, не подключается к пользовательскому Chrome и не использует его аккаунты. Результат — `latest-browser.json`; вспомогательная проверка ссылок/обложек этого исследования — `links-and-images.json`. `dist/` исключён из Git, поэтому машинные отчёты останутся локальными; этот документ содержит устойчивое резюме для переноса проекта.

Проверки кода: **93 теста прошли**, включая 8 новых проверок границ времени, обычных скидок, будущих предложений, демо, неизвестной цены, повреждённых ответов и диагностирования сети. Работающий интерфейс не изменён; полный набор визуальных проверок и релизная упаковка для этого исследовательского этапа не требуются.
